# Data Mining Laboratory (DML) - IUST

Official research laboratory website for the **Data Mining Laboratory (DML)** at the School of Computer Engineering, Iran University of Science and Technology (IUST).

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

### 4. Sync Google Scholar Publications
```bash
npm run sync:scholar
```
